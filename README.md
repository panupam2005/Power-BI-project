# Power-BI-project


Super Store Sales Analysis and Forecasting

Developed an interactive Power BI dashboard analyzing superstore sales data. Key features included:
Metrics:
Total sales: ₹1.57M
Total quantity sold: 22K
Total profit: ₹175.26K
Average delivery days: 4
Insights into sales and profit trends (2019–2020), region-wise performance, segment, and ship mode analysis.
Product performance by category and sub-category.
Integrated time-series analysis for a 15-day sales forecast, enabling data-driven business decisions and strategic planning.
